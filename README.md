# Real Estate Analytics Report

## 📊 О проекте

Данный проект представляет собой **полный цикл статистического анализа** рынка недвижимости на основе данных о 500 объектах. В рамках исследования были решены следующие задачи:

- Выявление ключевых факторов, определяющих стоимость недвижимости, с помощью корреляционного и регрессионного анализа.
- Построение множественной линейной регрессии с логарифмированием цены для интерпретации коэффициентов в процентах.
- Проверка статистической значимости каждого фактора с коррекцией на гетероскедастичность (робастные стандартные ошибки HC3).
- Диагностика модели: тест Бройша-Пагана, VIF-анализ мультиколлинеарности, визуальная проверка остатков.
- Формирование практических рекомендаций для покупателей, продавцов и инвесторов на основе количественных оценок.

Проект включает все этапы: от загрузки и предобработки данных до построения модели, проверки предположений и генерации итогового отчёта.

📈 Анализ и визуализация
1. Корреляционный анализ
Построена тепловая карта корреляций между всеми числовыми признаками. Выявлены сильные связи:

Признак	Корреляция с ценой
| Признак | Корреляция с ценой |
|---------|-------------------:|
| Жилая площадь (interior_space_sqm) | 0.937 |
| Тип «отдельный дом» (House) | 0.801 |
| Площадь участка (land_size_sqm) | 0.765 |
| Наличие гаража (garage) | 0.443 |
| Возраст здания (property_age_years) | 0.191 |
| Тип «квартира» (Apartment) | –0.645 |

Площадь участка сильно коррелирует с жилой площадью (0.67) и типом «дом» (0.86), что указывает на мультиколлинеарность. В финальную модель включена только жилая площадь.

https://images/correlation_matrix.png

2. Регрессионная модель
Построена множественная линейная регрессия с логарифмированной ценой (log_price) в качестве зависимой переменной. Предикторы:

Тип недвижимости: кондо, таунхаус, квартира (базовый уровень – отдельный дом)

Наличие гаража (бинарный)

Жилая площадь (кв. м)

Возраст здания (годы)

Результаты модели (с робастными стандартными ошибками HC3):

Признак	Коэффициент	Робастная ошибка	P-значение	95% Доверительный интервал
| Признак | Коэффициент | Робастная ошибка | P-значение | 95% Доверительный интервал |
|---------|------------:|-----------------:|-----------:|----------------------------:|
| Кондо (Condo) | –0.3255 | 0.0419 | < 0.001 | [–0.408; –0.243] |
| Таунхаус (Town) | –0.1502 | 0.0198 | < 0.001 | [–0.189; –0.111] |
| Квартира (Apartment) | –0.4628 | 0.0374 | < 0.001 | [–0.536; –0.389] |
| Гараж (garage) | 0.0374 | 0.0196 | 0.0565 | [–0.0012; 0.0760] |
| Жилая площадь (interior_space_sqm) | 0.00566 | 0.000272 | < 0.001 | [0.00513; 0.00619] |
| Возраст (property_age_years) | –0.00355 | 0.000471 | < 0.001 | [–0.00448; –0.00263] |

R² = 0.8748 – модель объясняет 87.48% вариации цен.

Скорректированный R² = 0.8733 – нет переобучения.

F-статистика = 574.4 (p < 0.001) – модель значима в целом.

3. Диагностика модели
Тест Бройша-Пагана (p < 0.001) подтвердил наличие гетероскедастичности. Для коррекции использованы робастные стандартные ошибки HC3, что привело к увеличению стандартных ошибок для некоторых коэффициентов (например, для «кондо» на 17%, для «квартиры» на 6%).

VIF-анализ показал отсутствие мультиколлинеарности (все значения VIF < 10):

Кондо: 2.03

Таунхаус: 1.50

Квартира: 3.71

Гараж: 1.36

Жилая площадь: 3.06

Возраст: 1.13

График остатков (зависимость остатков от предсказанных значений, QQ-plot, гистограмма) подтвердил адекватность модели: остатки случайно разбросаны вокруг нуля, распределение близко к нормальному, фактические и предсказанные значения хорошо согласуются.

Модель позволяет прогнозировать цену для новых объектов. Примеры:

📌 Результаты и рекомендации
Жилая площадь – абсолютный лидер по влиянию: каждый дополнительный м² увеличивает цену на 0.57%. Прирост цены при увеличении площади с 100 до 200 м² (при прочих равных) составляет примерно +114%.

Тип недвижимости – дома стоят на 46% дороже квартир, на 33% дороже кондо и на 15% дороже таунхаусов.

Возраст – каждый год снижает стоимость на 0.36%. Для 30-летнего дома это даёт снижение примерно на 10.8% по сравнению с новым.

Наличие гаража статистически незначимо (p = 0.0565) – не стоит переплачивать за этот признак.

Модель объясняет 87.5% вариации цен, что делает её надёжным инструментом для оценки и инвестиционного анализа.

Рекомендации:

Покупателям – ориентироваться на жилую площадь и тип объекта, отдавая предпочтение новым домам. Гараж не должен быть фактором переплаты.

Продавцам – акцент в маркетинге делать на площади и малом возрасте, а не на гараже.

Инвесторам – отдельные дома с большой площадью и малым возрастом дают максимальную перепродажную стоимость.
